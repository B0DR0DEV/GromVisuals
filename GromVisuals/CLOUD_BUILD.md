# Облачная сборка GromVisuals (без Gradle на твоём ПК)

## 1. Создай репозиторий GitHub
1. Открой https://github.com/new и войди в свой аккаунт.
2. Назови репозиторий `GromVisuals`.
3. Выбери **Public** (так проще использовать GitHub Actions на бесплатном тарифе) или Private, если твой тариф допускает Actions.
4. Нажми **Create repository**.

## 2. Загрузи проект
1. Распакуй ZIP на компьютере.
2. Открой созданный репозиторий на GitHub.
3. Нажми **Add file → Upload files**.
4. Перетащи содержимое папки проекта, включая папку `.github` и файл `.github/workflows/build.yml`. Важно: загружай содержимое проекта, а не ZIP как один файл.
5. Нажми **Commit changes**.

## 3. Запусти облачную сборку
1. Открой вкладку **Actions** в репозитории.
2. Если GitHub попросит разрешить workflows, подтверди.
3. Выбери workflow **Build GromVisuals**.
4. Нажми **Run workflow → Run workflow**. Если workflow запустился автоматически после commit, просто открой последний запуск.
5. Дождись зелёной галочки. Если сборка упала, открой запуск и скопируй лог ошибки.

## 4. Скачай JAR
1. Открой успешный запуск workflow.
2. Внизу найди раздел **Artifacts**.
3. Скачай `GromVisuals-Minecraft-1.21.11`.
4. Распакуй скачанный ZIP-артефакт. Внутри будет `.jar`.
5. Помести JAR в `%AppData%\\.minecraft\\mods` вместе с Fabric Loader и подходящим Fabric API.

## Безопасность
- Workflow использует GitHub-hosted runner и не просит доступ к личным файлам на твоём ПК.
- В workflow указаны права `contents: read`, необходимые для чтения исходников.
- Не добавляй в репозиторий пароли, токены или другие секреты.
- JAR появляется только если сборка действительно прошла успешно.
- Это не гарантия, что код уже компилируется: если API/версии в исходниках несовместимы, GitHub Actions покажет ошибку. Тогда нужно исправить лог и запустить сборку снова.
