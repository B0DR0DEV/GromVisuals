# GromVisuals

Клиентский Fabric-мод с фиолетовым неоновым HUD в стиле ГромКлиента для Minecraft Java 1.21.11.

## Возможности текущей версии обновления
- Right Shift открывает меню без ванильного blur — это устраняет известную причину вылета `Can only blur once per frame`.
- Новое меню с категориями HUD / VISUALS / COSMETICS / GENERAL, прокруткой и переключателями.
- HUD: FPS, координаты XYZ, CPS, WASD + SPACE, LMB/RMB, направление, ping, локальные часы, скорость, биом.
- Дополнительные модули: отображение брони с полосками прочности, прочность предмета в руке, эффекты зелий, кастомный прицел, Target HUD, голод/насыщение, предупреждения о низкой прочности брони и низком здоровье.
- Внешний вид: темы GROM / Purple / Neon / White, акцентные цвета, компактный HUD, настройка масштаба и прозрачности панелей.
- Настройки сохраняются в `config/grom-visuals.json`.
- Полностью клиентский мод: не меняет игровые характеристики и не отправляет данные на сервер.

## Важно о косметике
Вкладка COSMETICS пока содержит сохранённые переключатели-заготовки для China Hat, Halo, Wings, Devil Horns и частиц. Их 3D-рендеринг на модели игрока ещё не реализован в этой версии; переключатели не создают косметику в игровом мире. Это следующий отдельный этап разработки, а не готовая функция.

## Требования
- Minecraft Java Edition **1.21.11**
- Fabric Loader для 1.21.11
- Fabric API для 1.21.11
- Java/JDK 21 для сборки
- Интернет для первого запуска сборки (скрипт сам скачает официальный Gradle во временную папку проекта, проверит SHA-256 и запустит его; отдельная установка не нужна)

## Сборка на Windows
1. Установи JDK 21 и Gradle.
2. Распакуй проект в папку без кириллицы в пути, например `C:\Mods\GromVisuals`.
3. Запусти `build.bat`.
4. Готовый JAR появится в `build\libs\grom-visuals-1.0.0.jar`.
5. Скопируй JAR в `%AppData%\.minecraft\mods`.

Первый запуск скачает Gradle с официального сайта, а затем зависимости из Fabric Maven и Maven Central. Нужен интернет. Скрипт не требует прав администратора. Перед запуском можешь открыть `build.bat` в Блокноте и проверить команды: загрузка выполняется через PowerShell с HTTPS; архив проверяется по SHA-256. Скрипт не запускает установщик и не требует прав администратора.

## Управление
- `Right Shift` — открыть/закрыть меню.
- Переключай категории сверху и нажимай по строкам, чтобы менять параметры.
- Колёсико мыши прокручивает список.
- `THEME` внизу циклически меняет тему.
- `DONE` закрывает меню.

## Примечание
Это исходный проект, который собирает JAR на твоём компьютере. Предварительно собранный и протестированный JAR в архив не вложен. После сборки сначала проверь мод в одиночном мире.


## Облачная сборка без Gradle на ПК
Смотри `CLOUD_BUILD.md`. Workflow находится в `.github/workflows/build.yml`; GitHub Actions собирает JAR и публикует его как артефакт `GromVisuals-Minecraft-1.21.11`.


Облачный workflow поддерживает Gradle-проект в корне репозитория или в папке `GromVisuals/`. См. `CLOUD_BUILD.md`.

Текущая конфигурация облачной сборки: Gradle 9.2.0 + Fabric Loom 1.14.10.
